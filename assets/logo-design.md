## 1. 核心概念

**Chariot = 能自动进化的智能体**。项目名字取自"战车"—— 承载、驱动、向前 —— 隐喻一个不断自我迭代、把能力向前推进的 agent。

Logo 要在视觉上同时传达三层意思：

| 语义 | 视觉化 |
|---|---|
| **承载** | 轮子（封闭环 + 辐条）—— 支撑、流转 |
| **掌控** | 轴（贯穿的横梁）—— 方向、结构支点 |
| **内核驱动** | 轴心（暖色圆盘）—— 被驾驭的焦点 |

避免具象战车（古典兵器感和 AI 前沿调性冲突），整体抽象为"轮 + 轴 + 轴心"的几何组合。

## 2. 元素拆解

```
┌─────────────────────────────────────┐
│          · · · · · · · ·            │  ← 轮圈 (Ring)
│       \    |         |    /         │
│     \      |         |      /       │  ← 辐条 (Spokes) × 8
│   ──────────────●──────────────     │  ← 轴 (Axle) + 轴心 (Hub)
│     /      |         |      \       │
│       /    |         |    \         │
│          · · · · · · · ·            │
└─────────────────────────────────────┘
```

### 2.1 轮圈 (Ring)
- 几何：圆心 (128, 128)，半径 100，stroke-width 6
- 颜色：蓝青渐变 `#3D5AF1 → #22D1EE`
- 语义：封闭的环 = 完整性、周期性、反复迭代的轨道

### 2.2 辐条 (Spokes)
- 数量：**8 条**，严格每 **36°** 一根
- 方位：36°, 72°, 108°, 144°, 216°, 252°, 288°, 324°（东/西 0°/180° 让位给轴）
- 粗细：顺时针渐粗，stroke **2.5 → 6**
- 语义：**渐粗节奏 = 每一代迭代让结构更完整**，对应 auto-evolving 的核心主张

### 2.3 轴 (Axle)
- 几何：水平横线 x=4 → x=252，y=128，stroke-width 6
- 颜色：与轮圈同一渐变 `url(#ga)`
- 重点：**两端突出轮圈 ~21px**，清晰"穿过"整个画面，是把 "轮子" 升级为 "战车" 的关键信号
- 绘制顺序：在轮圈和辐条之上、轴心之下（轴从轴心后面穿过，轴心盖在最上层）

### 2.4 轴心 (Hub)
- 几何：圆心 (128, 128)，半径 12，填充
- 颜色：**浅琥珀金 `#F4CB78`** —— 画面唯一的暖色
- 语义：整个系统的"内核"。冷色轮体围绕一个暖色核心旋转 —— 隐喻：agent 的自我进化由一个稳定内核驱动

## 3. 配色

| 角色 | 颜色 | 象征 |
|---|---|---|
| 主渐变（轮、辐、轴） | `#3D5AF1 → #22D1EE` | 理性、科技、流动的冷色系 |
| 焦点（轴心） | `#F4CB78` | 温度、生命、内核驱动力 |

冷暖对比不仅是视觉对位，也是语义对位：**冷色 = 被驾驭的载体；暖色 = 驱动的意志**。

### SVG 渐变写法注意

渐变定义必须使用 `gradientUnits="userSpaceOnUse"`：

```xml
<linearGradient id="ga" gradientUnits="userSpaceOnUse" x1="0" y1="0" x2="256" y2="256">
  <stop offset="0" stop-color="#3D5AF1"/>
  <stop offset="1" stop-color="#22D1EE"/>
</linearGradient>
```

原因：默认的 `objectBoundingBox` 在目标元素是**纯水平线**（几何高度 0）时退化，多数浏览器直接不渲染。轴是一条纯水平线，必须用绝对坐标系的渐变。

## 4. 设计决策历程

### 4.1 为什么不做更写实的战车？
写实战车（驭手、马、车厢）携带强烈的古典兵器感，和 "AI / 自我进化" 的前沿语境冲突。抽象为 "轮 + 轴" 保留隐喻，丢掉包袱。

### 4.2 为什么辐条粗细不均？
均匀辐条读起来是"齿轮"或"罗盘"；渐粗辐条暗示时间/版本累积 —— 每一次迭代都让结构更厚实。这是整个 Logo 里唯一直接对应 **auto-evolving** 的视觉元素。

### 4.3 为什么轴和轮圈同色？
尝试过把轴做成琥珀金做对比，视觉太跳，语义变成"暖色结构 + 冷色包裹"，和"轮承载驱动力"的直觉相反。改回同色蓝青后，轴成为轮体的自然延伸，暖色只留给最内核的轴心。

### 4.4 为什么轴心是暖色？
整个画面如果全是冷色，缺焦点；放一个高饱和暖色点睛最经济。从 `#E8B13B`（饱和琥珀）降到 `#F4CB78`（柔化金）—— 既是焦点，又不喧宾夺主。

### 4.5 为什么去掉了运动残影？
早期版本在轮子左侧加了 4 条水平残影线，想暗示"滚动向前"。实践中发现：
- 残影和轴都是水平线，互相抢视觉；
- 画面本身已经有轴的方向性（水平突出），不需要额外运动提示；
- 减法让整体更克制。

## 5. 使用指南

### 5.1 应用场景
- **README / 文档头图**：`<img src="assets/logo.svg" width="140" />`（已用在项目 README 里）
- **Favicon / app icon**：256×256 SVG 直接用即可；浏览器会缩放。更小尺寸（16×16）可读性尚未单独优化，需要时做专门的简化版。
- **深色背景**：当前版本为浅色背景优化；深色模式下建议生成反色版（未实现，需要时再做）。

### 5.2 tagline
- 主：*Self-evolving intelligence, in motion.*
- 中：驾驭智能，向前。
- 备：*The agent that drives itself forward.*

### 5.3 禁区
- 不要拉伸变形（保持 1:1 比例）。
- 不要改变轴穿过画面的水平贯通性（两端必须伸出轮圈）。
- 不要把轴心改成冷色（会失去画面唯一焦点）。
